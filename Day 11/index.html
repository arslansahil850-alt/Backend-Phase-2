Introduction & Prerequisites

What & Why Middleware?

At its core, an Express application is essentially a stack of middleware functions. Middleware functions are blocks of code that have access to the request object (`req`), response object (`res`), and the `next` middleware function in the application’s request-response cycle.

Middleware enables logging, authentication, request validation, and payload parsing cleanly and modularly.

Prerequisites

  • Day 07 Knowledge: Understanding Express application initialization (`app.get()`, `app.use()`).
  • Day 09 Knowledge: Using built-in body parsers like `express.json()`.

Lesson 11.1

Writing Custom Middleware & The Role of `next()`

Every middleware function receives `req`, `res`, and `next`. If you do not call `next()` or send a response, the request will hang indefinitely.

middleware-demo.js 
const express = require('express');
const app = express();

// Custom Logger Middleware
const requestLogger = (req, res, next) => {
    const timestamp = new Date().toISOString();
    console.log(`[${timestamp}] ${req.method} request made to: ${req.url}`);
    
    // Pass control to the next middleware or route handler
    next();
};

// Mount globally
app.use(requestLogger);

app.get('/', (req, res) => {
    res.send('Home Page with Logger Middleware');
});

app.listen(3000);
Key Takeaway:

Calling `next()` hands execution over to the subsequent middleware in line. Omitting it freezes the request cycle.

Lesson 11.2

Authentication Middleware & Third-Party Logging (Morgan)

Middleware can inspect headers for API keys or tokens before allowing requests to reach protected routes. Additionally, third-party packages like Morgan simplify HTTP request logging.

auth-morgan.js 
const express = require('express');
const morgan = require('morgan'); // npm install morgan
const app = express();

// Mount Morgan logger middleware
app.use(morgan('dev'));

// Custom API Key Authentication Middleware
const authenticateApiKey = (req, res, next) => {
    const apiKey = req.headers['x-api-key'];

    if (!apiKey || apiKey !== 'arslan-secret-key-123') {
        return res.status(401).json({ error: 'Unauthorized: Invalid or missing API Key' });
    }

    next();
};

// Protected Route utilizing auth middleware
app.get('/api/admin/dashboard', authenticateApiKey, (req, res) => {
    res.json({ success: true, message: 'Welcome to the protected admin dashboard!' });
});

app.listen(3000);

Daily Project: Secure Express API with Custom Logger & Auth Middleware

Build a Production-Ready Middleware Pipeline Server

Project Phase 2 - Day 11

Description: Build an Express server featuring custom request logging middleware, Morgan integration, static file serving, and route-specific API key authentication.

Key Requirements:

  • Mount Morgan and custom timestamp logger middleware globally.
  • Serve static frontend assets via `express.static()`.
  • Protect `/api/admin` endpoints using custom authentication middleware.
server.js 
// Secure Express API with Middleware Pipeline
const express = require('express');
const morgan = require('morgan');
const app = express();
const PORT = 3000;

// 1. Built-in & Third-Party Middleware
app.use(express.json());
app.use(morgan('dev'));
app.use(express.static('public'));

// 2. Custom Request Timestamp Logger Middleware
const requestTimestampLogger = (req, res, next) => {
    req.requestedAt = new Date().toISOString();
    console.log(`[${req.requestedAt}] Incoming ${req.method} request to ${req.url}`);
    next();
};

app.use(requestTimestampLogger);

// 3. Custom Authentication Middleware
const requireApiKey = (req, res, next) => {
    const apiKey = req.headers['authorization'];
    
    if (!apiKey || apiKey !== 'Bearer arslan-secret-token') {
        return res.status(401).json({
            success: false,
            error: 'Access Denied: Missing or invalid Bearer token'
        });
    }
    next();
};

// Public Routes
app.get('/', (req, res) => {
    res.send('Welcome to Arslan Middleware Masterclass API!');
});

app.get('/api/public/status', (req, res) => {
    res.json({ status: 'ONLINE', checkedAt: req.requestedAt });
});

// Protected Admin Route (Using requireApiKey middleware)
app.get('/api/admin/metrics', requireApiKey, (req, res) => {
    res.json({
        success: true,
        metrics: {
            activeUsers: 1420,
            serverUptime: process.uptime(),
            authorizedBy: 'Arslan Admin Auth'
        }
    });
});

// 404 Catch-All
app.use((req, res) => {
    res.status(404).json({ error: 'Endpoint not found' });
});

app.listen(PORT, () => {
    console.log(`🚀 Secure middleware server active at http://localhost:${PORT}`);
});

Conceptual Knowledge Checks

True or False

1. Middleware functions must call `next()` or send a response to prevent request hanging.

TRUE: Without `next()` or a response, the client connection hangs indefinitely.

2. `app.use()` is used to mount middleware functions globally in Express.

TRUE: `app.use()` applies middleware across matching routes.

3. Morgan is a built-in core module of Node.js that requires no npm installation.

FALSE: Morgan is an external third-party logging package installed via `npm install morgan`.

Answer: express.static()

Answer: morgan
