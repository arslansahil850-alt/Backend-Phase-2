Introduction & Prerequisites

What & Why Native HTTP Servers?

Before diving into frameworks like Express.js, every backend developer must understand how Node.js creates servers natively using the built-in http module.

Building a native server gives you a deep appreciation for how request parsing, header writing, and response streaming operate under the hood.

Prerequisites

  • Day 05 Knowledge: Strong grasp of HTTP methods, status codes, and headers.
  • Day 02 Modules: Using CommonJS `require()` syntax.
  • Terminal Usage: Running server processes and testing endpoints in a browser or Postman.

Detailed Lessons & Code Demonstrations

Lesson 6.1

Creating Your First Native HTTP Server

The `http.createServer()` method accepts a callback function executed every time an HTTP request hits the server. This callback receives two objects: `req` (IncomingMessage) and `res` (ServerResponse).

server.js 
const http = require('http');

const PORT = 3000;

const server = http.createServer((req, res) => {
    console.log(`Received request for: ${req.url} using method: ${req.method}`);

    // Set response header
    res.writeHead(200, { 'Content-Type': 'text/plain' });

    // Send response body and end connection
    res.end('Hello from Arslan Native Node Server!\n');
});

server.listen(PORT, () => {
    console.log(`🚀 Server running at http://localhost:${PORT}/`);
});
Line-by-Line Breakdown:
  • http.createServer(...): Initializes the HTTP server instance.
  • res.writeHead(200, {...}): Sets the HTTP status code and response headers.
  • res.end(...): Sends the final output to the client and terminates the response cycle.
Lesson 6.2

Manual URL Routing & JSON Responses

Native Node.js does not have built-in routers. To handle different URLs (like `/` vs `/api/users`), you inspect `req.url` and `req.method` using standard conditional statements.

api-server.js 
const http = require('http');

const server = http.createServer((req, res) => {
    if (req.url === '/' && req.method === 'GET') {
        res.writeHead(200, { 'Content-Type': 'text/plain' });
        res.end('Welcome to the Home Page');
    } 
    else if (req.url === '/api/users' && req.method === 'GET') {
        const users = [{ id: 1, name: 'Arslan' }, { id: 2, name: 'Ali' }];
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ success: true, data: users }));
    } 
    else {
        res.writeHead(404, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ error: 'Endpoint Not Found' }));
    }
});

server.listen(3000, () => {
    console.log("Router server active on port 3000");
});

Daily Project: Native Node.js Multi-Route API Server

Build a Complete Native Multi-Endpoint Backend Server

Project Phase 2 - Day 06

Description: Build a fully functional native Node.js HTTP server featuring multiple endpoints (`/`, `/api/status`, `/api/products`), strict method checking, JSON responses, and proper 404 handling.

Key Requirements:

  • Handle GET requests for root (`/`), status (`/api/status`), and products (`/api/products`).
  • Return structured JSON responses with correct `Content-Type` headers.
  • Return 404 Not Found for unregistered routes.
native-server.js 
// Native Node.js Multi-Route API Server
const http = require('http');

const PORT = 3000;

const server = http.createServer((req, res) => {
    // Enable CORS headers
    res.setHeader('Access-Control-Allow-Origin', '*');
    res.setHeader('Access-Control-Allow-Methods', 'GET, OPTIONS');

    if (req.method !== 'GET') {
        res.writeHead(405, { 'Content-Type': 'application/json' });
        return res.end(JSON.stringify({ error: 'Method Not Allowed' }));
    }

    if (req.url === '/') {
        res.writeHead(200, { 'Content-Type': 'text/plain' });
        res.end('Welcome to Arslan Native Node API Server!');
    } 
    else if (req.url === '/api/status') {
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({
            status: 'ONLINE',
            uptimeSeconds: Math.floor(process.uptime()),
            timestamp: new Date().toISOString()
        }));
    } 
    else if (req.url === '/api/products') {
        const products = [
            { id: 101, title: 'Node.js Masterclass', price: 49.99 },
            { id: 102, title: 'Express.js Handbook', price: 29.99 }
        ];
        res.writeHead(200, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ count: products.length, data: products }));
    } 
    else {
        res.writeHead(404, { 'Content-Type': 'application/json' });
        res.end(JSON.stringify({ error: 'Endpoint Not Found' }));
    }
});

server.listen(PORT, () => {
    console.log(`🚀 Native server active at http://localhost:${PORT}`);
});

True or False

FALSE: `http` is a built-in core module of Node.js.

2. `res.writeHead()` is used to set status codes and response headers.

TRUE: It writes headers before sending the response body.

3. Native Node.js has a built-in router that automatically handles URL parameters.

FALSE: Native Node requires manual conditional logic or external frameworks like Express.

Quick Concepts

1. What method creates an HTTP server instance in Node.js?

Answer: http.createServer()

2. What method terminates the response cycle and sends data to the client?

Answer: res.end()

3. How do you convert a JavaScript object into a JSON string before sending it?

Answer: JSON.stringify()

Day 06 Quick Revision Cheat-Sheet

http.createServer

Core Node method used to spin up backend HTTP servers and handle incoming connections.

Req & Res

req inspects incoming URL and method. res writes headers and sends responses.

writeHead

Sets HTTP status code and response header metadata like Content-Type.

res.end()

Finalizes and sends the response payload back to the client.
