Introduction & Prerequisites

What & Why Core Modules?

Node.js comes pre-packed with powerful core modules that require zero external installation (`npm install`). Among the most critical for backend developers are fs (File System), path (File Path Resolution), and os (Operating System Utilities).

These built-in modules allow your backend server to read configuration files, write logs, handle user uploads, and query server hardware specs directly.

Prerequisites

  • Day 03 Knowledge: Understanding CommonJS modules (`require()`) and project structures.
  • Asynchronous JavaScript: Familiarity with callbacks, Promises, and `async/await`.
  • File System Concepts: Understanding file paths (`/` vs `\`).

Detailed Lessons & Code Demonstrations

Lesson 4.1

The File System (`fs`) Module

The `fs` module enables interacting with the local machine hard drive. Almost every file method comes in two flavors: Synchronous (blocking execution) and Asynchronous (non-blocking).

fs-demo.js (fs/promises) 
const fs = require('fs/promises');
const path = require('path');

async function handleFiles() {
    try {
        const filePath = path.join(__dirname, 'notes.txt');

        // 1. Write file asynchronously
        await fs.writeFile(filePath, "Hello from Arslan's Backend Platform!\n");
        console.log("File written successfully!");

        // 2. Append to file
        await fs.appendFile(filePath, "Adding a new log entry.\n");
        console.log("File appended successfully!");

        // 3. Read file contents
        const data = await fs.readFile(filePath, 'utf8');
        console.log("File Content:\n", data);

    } catch (error) {
        console.error("File system error:", error);
    }
}

handleFiles();
Line-by-Line Breakdown:
  • require('fs/promises'): Imports the modern promise-based file system API, enabling `async/await`.
  • fs.writeFile(): Creates or overwrites a file with specified string data.
  • fs.readFile(path, 'utf8'): Reads the file and decodes buffer bytes into a readable string format.
Lesson 4.2

The Path (`path`) Module

Different operating systems use different path separators (`\` on Windows, `/` on macOS/Linux). Hardcoding paths with slashes causes production bugs. The `path` module handles this automatically.

path-demo.js 
const path = require('path');

// Safe cross-platform path joining
const fullPath = path.join(__dirname, 'public', 'assets', 'style.css');
console.log("Joined Path:", fullPath);

// Extracting file details
console.log("File Extension:", path.extname(fullPath)); // .css
console.log("Base Filename:", path.basename(fullPath));   // style.css
console.log("Directory Name:", path.dirname(fullPath));   // .../public/assets
Lesson 4.3

The Operating System (`os`) Module

The `os` module provides operating system-related utility methods and properties for querying server hardware metrics.

os-demo.js 
const os = require('os');

console.log("Operating System Platform:", os.platform()); // win32 / darwin / linux
console.log("CPU Architecture:", os.arch());             // x64 / arm64
console.log("Total RAM (GB):", (os.totalmem() / 1024 / 1024 / 1024).toFixed(2));
console.log("Free RAM (GB):", (os.freemem() / 1024 / 1024 / 1024).toFixed(2));
console.log("OS Uptime (Hours):", (os.uptime() / 3600).toFixed(2));

Easy

Exercise 1: Safe Path Resolver

const path = require('path');
const logPath = path.join(__dirname, 'logs', 'server.log');

Medium

Exercise 2: Asynchronous Log Writer

Write an async function using `fs/promises` that writes a timestamped error message to `error.log`.

const fs = require('fs/promises');

async function writeLog(msg) {
    const log = `[${new Date().toISOString()}]: ${msg}\n`;
    await fs.appendFile('error.log', log);
}
writeLog("Database timeout connection error.");
Medium

Exercise 3: OS Free Memory Formatter

Use the `os` module to calculate and print available free memory percentage relative to total system memory.

const os = require('os');
const free = os.freemem();
const total = os.totalmem();
const percentFree = ((free / total) * 100).toFixed(2);
console.log(`Free RAM: ${percentFree}%`);
Hard

Exercise 4: Automatic Directory Creator

Write a script that checks if a `uploads/` folder exists; if it does not, create it programmatically using `fs.mkdir()`.

const fs = require('fs');
const dir = './uploads';

if (!fs.existsSync(dir)) {
    fs.mkdirSync(dir, { recursive: true });
    console.log("Uploads folder created successfully.");
}
Hard

Exercise 5: File Extension Extractor CLI

Read a filename passed via `process.argv` and use `path.extname()` and `path.basename()` to log its details.

const path = require('path');
const fileInput = process.argv[2] || 'index.html';

console.log("Filename:", path.basename(fileInput));
console.log("Extension:", path.extname(fileInput));

Daily Project: Automated System Log Analyzer & Report Generator

Build a File System & OS Audit CLI Utility

Project Phase 2 - Day 04

Description: Build a comprehensive Node script that gathers server operating system metrics (CPU, RAM, platform) and writes a detailed audit report into a formatted text file (`system-report.txt`).

Key Requirements:

  • Combine `os`, `fs/promises`, and `path` modules.
  • Format hardware metrics into a clean text report.
  • Save the report asynchronously to the local file system.
audit-report.js 
// System Audit & Log Report Generator
const os = require('os');
const fs = require('fs/promises');
const path = require('path');

async function generateAuditReport() {
    const reportData = `==========================================
   ARSLAN BACKEND SERVER AUDIT REPORT
==========================================
Timestamp   : ${new Date().toISOString()}
Platform    : ${os.platform()} (${os.arch()})
CPU Cores   : ${os.cpus().length} cores
Total RAM   : ${(os.totalmem() / 1024 / 1024 / 1024).toFixed(2)} GB
Free RAM    : ${(os.freemem() / 1024 / 1024 / 1024).toFixed(2)} GB
OS Uptime   : ${(os.uptime() / 3600).toFixed(2)} hours
==========================================\n`;

    const reportPath = path.join(__dirname, 'system-report.txt');
    
    try {
        await fs.writeFile(reportPath, reportData);
        console.log("✅ System audit report successfully generated at:", reportPath);
    } catch (err) {
        console.error("❌ Failed to generate report:", err);
    }
}

generateAuditReport();
