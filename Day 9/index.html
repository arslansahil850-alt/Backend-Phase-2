Introduction & Prerequisites

What & Why POST Requests?

While GET requests retrieve data, POST requests send data from the client to the server (e.g., user registration, submitting forms, creating new database records).

By default, Express does not parse incoming request bodies automatically. You must mount the built-in express.json() middleware to read JSON payloads via req.body.

  • Day 07 Knowledge: Express app initialization and response methods.
  • JSON Format: Understanding JavaScript Object Notation syntax.

Detailed Lessons & Code Demonstrations

Lesson 9.1

Mounting `express.json()` Middleware

Without body parser middleware, `req.body` will be `undefined`. You must include `app.use(express.json())` before your route definitions.

post-demo.js 
const express = require('express');
const app = express();

// CRITICAL: Middleware to parse incoming JSON request bodies
app.use(express.json());

app.post('/api/users', (req, res) => {
    // req.body contains the parsed JSON payload from the client
    const { username, email } = req.body;

    if (!username || !email) {
        return res.status(400).json({ error: 'Username and email are required' });
    }

    const newUser = { id: Date.now(), username, email };

    // Return 201 Created status with the new resource
    res.status(201).json({
        success: true,
        message: 'User created successfully',
        data: newUser
    });
});

app.listen(3000);
Key Takeaway:

Always check if required body fields exist before processing database writes to prevent unhandled runtime errors.

Daily Project: Express Blog Post Creation API

Build a POST-Enabled Blog Article Creator API

Project Phase 2 - Day 09

Description: Build an Express server that supports fetching blog posts via GET and creating new articles via POST with robust input validation (`title` and `content`).

Key Requirements:

  • Mount `express.json()` middleware.
  • Implement GET `/api/posts` to list existing articles.
  • Implement POST `/api/posts` to create and store new articles with validation.
server.js 
// Express Blog Post Creation API
const express = require('express');
const app = express();
const PORT = 3000;

// Mount JSON Body Parser Middleware
app.use(express.json());

// In-Memory Blog Database
let posts = [
    { id: 1, title: 'Mastering Node.js Core Modules', content: 'Explore fs, path, and os...' },
    { id: 2, title: 'Introduction to Express Routing', content: 'Learn how to build endpoints...' }
];

// GET: Retrieve all blog posts
app.get('/api/posts', (req, res) => {
    res.json({ success: true, count: posts.length, data: posts });
});

// POST: Create a new blog post
app.post('/api/posts', (req, res) => {
    const { title, content, author } = req.body;

    // Validation check
    if (!title || !content) {
        return res.status(400).json({
            success: false,
            error: 'Both title and content are required fields'
        });
    }

    const newPost = {
        id: posts.length + 1,
        title,
        content,
        author: author || 'Arslan (Instructor)',
        createdAt: new Date().toISOString()
    };

    posts.push(newPost);

    res.status(201).json({
        success: true,
        message: 'Blog post created successfully',
        data: newPost
    });
});

app.listen(PORT, () => {
    console.log(`🚀 Blog API active at http://localhost:${PORT}`);
});

Conceptual Knowledge Checks

True or False

1. Express parses incoming JSON request bodies automatically without any middleware.

FALSE: You must mount `express.json()` middleware to parse JSON bodies.

2. `req.body` holds the parsed data submitted in a POST request.

TRUE: Body parser middleware populates `req.body`.

3. Status code 201 indicates a resource was successfully created.

TRUE: 201 Created is the standard REST status code for POST creations.

Quick Concepts

1. What middleware parses JSON request payloads in Express?

Answer: express.json()

2. What property on `req` contains the submitted form or JSON data?

Answer: req.body

3. What HTTP status code should be returned if required fields are missing during a POST request?

Answer: 400 Bad Request
