Introduction & Prerequisites

What & Why Express.js?

While native Node.js HTTP servers work, writing robust applications requires managing complex URL parsing, headers, and boilerplate code. Express.js is the de facto standard web framework for Node.js, providing a robust set of features for web and mobile applications.

Express simplifies routing, provides helper methods like `res.json()`, and introduces powerful middleware capabilities.

Prerequisites

  • Day 03 Knowledge: Managing packages and `package.json` with `npm`.
  • Day 06 Knowledge: Understanding HTTP methods and request-response cycles.
  • Terminal Usage: Installing packages via `npm install express`.

Detailed Lessons & Code Demonstrations

Lesson 7.1

Initializing Express & Your First Server

To use Express, you must first install it via npm (`npm install express`), then require it in your main application file.

app.js 
const express = require('express');
const app = express();
const PORT = 3000;

// Define a simple GET route
app.get('/', (req, res) => {
    res.send('Hello from Arslan Express Server!');
});

app.listen(PORT, () => {
    console.log(`🚀 Express server running at http://localhost:${PORT}`);
});
Line-by-Line Breakdown:
  • const express = require('express'): Imports the Express library.
  • const app = express(): Creates an Express application instance.
  • app.get('/', ...): Registers a route handler for GET requests to the root path.
Lesson 7.2

Clean JSON Responses with `res.json()`

In native Node, returning JSON required setting headers manually and calling `JSON.stringify()`. Express provides `res.json()`, which automatically sets the `Content-Type` to `application/json` and serializes objects.

api.js 
const express = require('express');
const app = express();

app.get('/api/instructors', (req, res) => {
    const instructors = [
        { id: 1, name: 'Arslan', role: 'Lead Backend Instructor' },
        { id: 2, name: 'Ali', role: 'DevOps Engineer' }
    ];

    // Express automatically sets Content-Type: application/json
    res.status(200).json({
        success: true,
        count: instructors.length,
        data: instructors
    });
});

app.listen(3000);

Daily Project: Express RESTful Course Catalog API

Build a Clean Express Course Catalog Server

Project Phase 2 - Day 07

Description: Build a complete Express.js server that serves a catalog of backend development courses with custom JSON responses and a 404 fallback handler.

Key Requirements:

  • Initialize Express app and listen on port 3000.
  • Create a GET route at `/api/courses` returning a JSON list of courses.
  • Add a 404 catch-all middleware for invalid endpoints.
server.js 
// Express Course Catalog API Server
const express = require('express');
const app = express();
const PORT = 3000;

// Mock database
const courses = [
    { id: 1, title: 'Node.js & Express Masterclass', instructor: 'Arslan', price: 49.99 },
    { id: 2, title: 'Advanced REST API Architecture', instructor: 'Arslan', price: 59.99 },
    { id: 3, title: 'MongoDB & Mongoose Bootcamp', instructor: 'Ali', price: 39.99 }
];

// Root Route
app.get('/', (req, res) => {
    res.send('Welcome to Arslan Backend Learning Platform API!');
});

// Courses API Endpoint
app.get('/api/courses', (req, res) => {
    res.status(200).json({
        success: true,
        count: courses.length,
        data: courses
    });
});

// 404 Catch-All Middleware
app.use((req, res) => {
    res.status(404).json({
        success: false,
        error: 'Endpoint not found on Arslan Server'
    });
});

app.listen(PORT, () => {
    console.log(`🚀 Express server running at http://localhost:${PORT}`);
});

Conceptual Knowledge Checks

True or False

1. Express.js is a built-in core module that comes pre-installed with Node.js.

FALSE: Express is an external third-party package installed via `npm install express`.

2. `res.json()` automatically sets the `Content-Type` header to `application/json`.

TRUE: It handles serialization and headers automatically.

3. `app.listen()` is used to bind and listen for connections on a specified port.

TRUE: It starts the Express server instance.

Quick Concepts

1. What command installs Express in your project?

Answer: npm install express

2. What Express method registers a GET route handler?

Answer: app.get()

3. How do you set a custom HTTP status code before sending a response in Express?

Answer: res.status(code)
