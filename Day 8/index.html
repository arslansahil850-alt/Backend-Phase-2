Introduction & Prerequisites

What & Why URL Parameters?

Real APIs are dynamic. You don't create a separate route for every individual user or product; instead, you use Route Parameters (e.g., `/api/users/:id`) to capture specific resource identifiers.

Additionally, when clients need to filter, sort, or paginate data (e.g., `/api/products?category=electronics&sort=price`), they use Query Parameters (`req.query`).

Prerequisites

  • Day 07 Knowledge: Express app setup and basic routing (`app.get()`).
  • URL Structure: Understanding paths, colons, and question marks (`?`).

Detailed Lessons & Code Demonstrations

Lesson 8.1

Route Parameters (`req.params`)

Route parameters are named URL segments prefixed with a colon (:). Express captures these values and populates them into the req.params object.

params-demo.js 
const express = require('express');
const app = express();

const users = [
    { id: 1, name: 'Arslan', role: 'Instructor' },
    { id: 2, name: 'Ali', role: 'Developer' }
];

// Single Route Parameter (:id)
app.get('/api/users/:id', (req, res) => {
    const userId = parseInt(req.params.id);
    const user = users.find(u => u.id === userId);

    if (!user) {
        return res.status(404).json({ error: 'User not found' });
    }

    res.json({ success: true, data: user });
});

app.listen(3000);
Key Takeaway:

If a client visits /api/users/1, Express sets req.params.id to "1" (string). Remember to parse numbers using parseInt() or Number().

Lesson 8.2

Query Parameters (`req.query`)

Query parameters are appended to the URL after a question mark (?) and separated by ampersands (&). Express automatically parses them into an object stored in req.query.

query-demo.js 
// Example URL: /api/search?q=express&sort=asc&limit=10
app.get('/api/search', (req, res) => {
    const { q, sort, limit } = req.query;

    res.json({
        message: 'Search results retrieved',
        searchQuery: q || 'none',
        sortBy: sort || 'default',
        resultLimit: limit ? parseInt(limit) : 20
    });
});

app.get('/api/products', (req, res) => {
    const { category } = req.query;
    // Filtering logic here...
    res.json({ filteredByCategory: category || 'all' });

Exercise 4: Handling 404 for Missing Resource ID

Given an array of items, look up an item by `req.params.id`. If not found, return status `404` with an error message.

app.get('/api/items/:id', (req, res) => {
    const item = items.find(i => i.id === parseInt(req.params.id));
    if (!item) return res.status(404).json({ error: 'Item not found' });
    res.json({ data: item });
});

Exercise 5: Pagination Query Handling

Extract `page` and `limit` query parameters, defaulting to `page = 1` and `limit = 10` if omitted.

app.get('/api/posts', (req, res) => {
    const page = parseInt(req.query.page) || 1;
    const limit = parseInt(req.query.limit) || 10;
    res.json({ page, limit });
});

Daily Project: Dynamic E-Commerce Filter & Detail API

Build a Parameter-Driven Product Catalog API

Project Phase 2 - Day 08

Description: Build an Express server featuring product listing with query parameter filtering (`?category=...&maxPrice=...`) and single-product lookup via route parameters (`/api/products/:id`).

Key Requirements:

  • Implement `/api/products` with query filtering (`category`, `maxPrice`).
  • Implement `/api/products/:id` with 404 error handling for missing IDs.
  • Return clean JSON responses.
server.js 
// Express Route & Query Parameters E-Commerce API
const express = require('express');
const app = express();
const PORT = 3000;

const products = [
    { id: 1, name: 'Mechanical Keyboard', category: 'electronics', price: 89.99 },
    { id: 2, name: 'Gaming Mouse', category: 'electronics', price: 49.99 },
    { id: 3, name: 'Ergonomic Desk Chair', category: 'furniture', price: 199.99 },
    { id: 4, name: 'Standing Desk', category: 'furniture', price: 349.99 }
];

// 1. Get Products with Optional Query Filtering (?category=...&maxPrice=...)
app.get('/api/products', (req, res) => {
    let results = [...products];
    const { category, maxPrice } = req.query;

    if (category) {
        results = results.filter(p => p.category.toLowerCase() === category.toLowerCase());
    }

    if (maxPrice) {
        results = results.filter(p => p.price <= parseFloat(maxPrice));
    }

    res.json({
        success: true,
        count: results.length,
        filters: { category: category || 'all', maxPrice: maxPrice || 'none' },
        data: results
    });
});

// 2. Get Single Product by Route Parameter (:id)
app.get('/api/products/:id', (req, res) => {
    const productId = parseInt(req.params.id);
    const product = products.find(p => p.id === productId);

    if (!product) {
        return res.status(404).json({ success: false, error: 'Product not found' });
    }

    res.json({ success: true, data: product });
});

app.listen(PORT, () => {
    console.log(`🚀 E-Commerce API active at http://localhost:${PORT}`);
});

Conceptual Knowledge Checks

True or False

1. Route parameters are accessed via `req.params` in Express.

TRUE: Named placeholders are stored in `req.params`.

2. Query parameters are prefixed with colons (`:`) in route definitions.

FALSE: Colons define route parameters. Query parameters are passed in URLs after `?`.

3. Express automatically parses query string key-values into `req.query`.

TRUE: `req.query` holds all query parameters as an object.

Quick Concepts

1. Which object holds query strings like `?sort=asc`?

Answer: req.query

2. How do you define a dynamic route parameter named `id`?

Answer: /:id

3. What status code should be returned if a requested resource ID does not exist?

Answer: 404 Not Found

Day 08 Quick Revision Cheat-Sheet

Route Parameters

Named URL segments like /users/:id accessed via req.params.

Query Parameters

URL search strings like ?sort=asc accessed via req.query.

Type Parsing

Parameters arrive as strings. Use parseInt() or Number() for numeric IDs.

Validation

Always verify if a resource exists before returning it; respond with 404 if missing.
