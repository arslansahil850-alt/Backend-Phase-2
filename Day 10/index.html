Introduction & Prerequisites

What & Why CRUD Updates & Deletions?

With GET (Read) and POST (Create) mastered, you now need to handle resource lifecycle modifications: PUT (full replacement), PATCH (partial update), and DELETE (removal).

Combining these methods fulfills the complete **CRUD** (Create, Read, Update, Delete) architecture required for professional RESTful APIs.

Prerequisites

  • Day 08 Knowledge: Capturing route parameters via `req.params`.
  • Day 09 Knowledge: Parsing request bodies using `express.json()`.

Detailed Lessons & Code Demonstrations

Lesson 10.1

PUT vs. PATCH: Full Replacement vs. Partial Updates

PUT implies replacing the entire resource entity. If any field is omitted in a PUT payload, it may be wiped out. PATCH modifies only the specific fields supplied in the request body.

update-demo.js 
const express = require('express');
const app = express();
app.use(express.json());

let users = [
    { id: 1, name: 'Arslan', email: 'arslan@dev.com', role: 'Admin' }
];

// PATCH: Partial Update
app.patch('/api/users/:id', (req, res) => {
    const userId = parseInt(req.params.id);
    const user = users.find(u => u.id === userId);

    if (!user) return res.status(404).json({ error: 'User not found' });

    // Update only supplied fields
    if (req.body.name) user.name = req.body.name;
    if (req.body.email) user.email = req.body.email;

    res.json({ success: true, data: user });
});

app.listen(3000);
Lesson 10.2

DELETE Requests: Removing Resources Safely

The DELETE method removes a resource identified by a route parameter. Always verify if the record exists before filtering or splicing your data array.

delete-demo.js 
// DELETE: Remove a user by ID
app.delete('/api/users/:id', (req, res) => {
    const userId = parseInt(req.params.id);
    const index = users.findIndex(u => u.id === userId);

    if (index === -1) {
        return res.status(404).json({ error: 'User not found' });
    }

    const deletedUser = users.splice(index, 1);

    res.json({
        success: true,
        message: 'User deleted successfully',
        data: deletedUser[0]
    });
});

Daily Project: Complete CRUD Product Inventory API

Build a Fully Functional CRUD Backend Server

Project Phase 2 - Day 10

Description: Build an Express.js API that implements all 5 core HTTP methods: GET (list & single), POST (create), PUT (replace), PATCH (update), and DELETE (remove).

Key Requirements:

  • GET `/api/inventory` & GET `/api/inventory/:id`
  • POST `/api/inventory` with body parsing and validation
  • PUT `/api/inventory/:id` and PATCH `/api/inventory/:id`
  • DELETE `/api/inventory/:id` with 404 error handling
server.js 
// Complete CRUD Product Inventory API
const express = require('express');
const app = express();
const PORT = 3000;

app.use(express.json());

let inventory = [
    { id: 1, name: 'Mechanical Keyboard', price: 89.99, stock: 15 },
    { id: 2, name: 'Gaming Mouse', price: 49.99, stock: 25 }
];

// 1. GET: List all inventory items
app.get('/api/inventory', (req, res) => {
    res.json({ success: true, count: inventory.length, data: inventory });
});

// 2. GET: Get single item by ID
app.get('/api/inventory/:id', (req, res) => {
    const item = inventory.find(i => i.id === parseInt(req.params.id));
    if (!item) return res.status(404).json({ error: 'Item not found' });
    res.json({ success: true, data: item });
});

// 3. POST: Create a new inventory item
app.post('/api/inventory', (req, res) => {
    const { name, price, stock } = req.body;
    if (!name || !price) {
        return res.status(400).json({ error: 'Name and price are required' });
    }
    const newItem = { id: Date.now(), name, price, stock: stock || 0 };
    inventory.push(newItem);
    res.status(201).json({ success: true, message: 'Item created', data: newItem });
});

// 4. PUT: Fully replace an inventory item
app.put('/api/inventory/:id', (req, res) => {
    const id = parseInt(req.params.id);
    const index = inventory.findIndex(i => i.id === id);
    if (index === -1) return res.status(404).json({ error: 'Item not found' });

    const { name, price, stock } = req.body;
    if (!name || !price) {
        return res.status(400).json({ error: 'Name and price required for PUT replacement' });
    }

    inventory[index] = { id, name, price, stock: stock || 0 };
    res.json({ success: true, message: 'Item fully replaced', data: inventory[index] });
});

// 5. PATCH: Partially update an inventory item
app.patch('/api/inventory/:id', (req, res) => {
    const item = inventory.find(i => i.id === parseInt(req.params.id));
    if (!item) return res.status(404).json({ error: 'Item not found' });

    if (req.body.name) item.name = req.body.name;
    if (req.body.price !== undefined) item.price = req.body.price;
    if (req.body.stock !== undefined) item.stock = req.body.stock;

    res.json({ success: true, message: 'Item updated partially', data: item });
});

// 6. DELETE: Remove an inventory item
app.delete('/api/inventory/:id', (req, res) => {
    const id = parseInt(req.params.id);
    const index = inventory.findIndex(i => i.id === id);
    if (index === -1) return res.status(404).json({ error: 'Item not found' });

    const deleted = inventory.splice(index, 1);
    res.json({ success: true, message: 'Item deleted', data: deleted[0] });
});

app.listen(PORT, () => {
    console.log(`🚀 CRUD Inventory API active at http://localhost:${PORT}`);
});
